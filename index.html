DAISY'S GARDEN

A re-imagined Space Invaders game in Python. Defend the garden from falling vines before they take all three of your hearts.

View on GitHub How to Play

Features

Custom sprites

Pixel-art daisy, vines and hearts made with .png and .gif files.

Three lives

Hearts act as extra lives. Lose one each time a vine lands or hits you.

Score & timer

Track how long you survive and how many vines you clear.

Tested rules

Movement, collision and lives logic are covered by automated pytest tests.

Controls

←→ move   Space fire   Q quit

Run it

  1. Install Python 3.10+ (turtle is built in).
  2. Place the image files in the same folder as the script.
  3. Run the game:
python daisys_garden.py
